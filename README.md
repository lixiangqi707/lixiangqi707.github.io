# Xiangqi Li academic homepage

Static GitHub Pages site. Open `index.html` locally to preview it; no build step is required. The layout takes cues from [Seil Kang](https://seilk.github.io/) and [Jon Barron](https://jonbarron.info/), with Xiangqi Li's own content and paper method figures.

## Publish

1. Create a public repository named `lixiangqi707.github.io` under the intended GitHub account.
2. Upload the files in this folder to the repository root.
3. In **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The site will appear at `https://lixiangqi707.github.io/` after GitHub Pages finishes deploying.

The username is inferred from the code repositories linked by the papers. If another account hosts the site, name the repository `<username>.github.io`.

## Edit

- Update biography, publications, news, and honors in `index.html`.
- Update layout and colors in `style.css`.
- Replace `assets/profile.png` with a preferred portrait if needed.
